# One Kakao Onboarding AI 실습 - 밸런스 게임

One Kakao Onboarding AI 실습 강의를 위한 첫번째 프로젝트입니다.

## 프로젝트 소개

**"나의 카카오 유니버스 적응 유형 찾기: Hello, New Krew!"**

간단한 밸런스 게임(예: "재택 vs 출근", "점심은 구내식당 vs 판교 맛집")을 통해 나의 업무 스타일과 성향을 분석하고, 4가지 K-크루 유형 중 하나를 도출하는 서비스입니다.

## 시작하기

1. `온보딩AI실습_01_밸런스게임.zip` 파일을 다운로드합니다.
2. zip 파일을 압축 해제합니다.
3. 기획서와 데이터를 참고하여 게임을 제작합니다.

## zip 파일 내용

- 기획서
- 밸런스 게임 제작에 필요한 데이터

## 게임 구성

### 밸런스 게임 질문 (5문항)

신입 크루가 회사 생활에서 마주칠 법한 상황을 카카오스러운 맥락으로 재해석한 질문들입니다.

- Q1: 출근 첫 주, 나의 업무 스타일은?
- Q2: 아지트에 업무 요청 알림이 떴을 때 나의 반응은?
- Q3: 점심시간, 동료들이 "오늘 뭐 먹을까요?"라고 묻는다면?
- Q4: 회의 중 기발하지만 실현 가능성이 낮은 아이디어가 나왔을 때?
- Q5: 내가 가장 듣고 싶은 피드백은?

### 결과 캐릭터 타입 (4가지)

| 유형 | 설명 |
|------|------|
| 🚀 스피드 레이서 (Speed Racer) | 빠른 실행력과 높은 텐션, 혁신의 아이콘 |
| 🔭 딥 다이버 (Deep Diver) | 본질을 꿰뚫는 기획자, 숲을 보는 현자 |
| 🎉 슈퍼 커넥터 (Super Connector) | 분위기 메이커, 소통의 허브 |
| 🛡️ 피스 메이커 (Peace Maker) | 갈등을 중재하고 팀을 지탱하는 수호자 |

### 캐릭터 결정 로직

- **X축 (행동 및 속도)**: Q1, Q2, Q4 → A가 많으면 빠름(Fast), B가 많으면 신중(Careful)
- **Y축 (가치관 및 소통)**: Q3, Q5 → A가 많으면 관계(People), B가 많으면 과업(Task)

| | 관계 지향 (A) | 과업 지향 (B) |
|---|---|---|
| **빠름 (A)** | 슈퍼 커넥터 | 스피드 레이서 |
| **신중 (B)** | 피스 메이커 | 딥 다이버 |
